# Καλαρρύτες: ο κατάλογος της ταβέρνας

Ο δημόσιος κατάλογος (μενού) της ταβέρνας στους Καλαρρύτες Τζουμέρκων, στα ελληνικά και στα αγγλικά:
https://konzag.github.io/kalarrytes-menu/

Δημοσιεύεται αυτόματα από το σύστημα κρατήσεων μόλις αλλάξει ο κατάλογος. Μην αλλάζετε αρχεία εδώ με το χέρι: η
επόμενη δημοσίευση θα τα αντικαταστήσει.

The taverna menu of Kalarrytes, Tzoumerka (Greek and English), published automatically from the booking system when
the menu changes. Do not edit files here by hand; the next publish replaces them.
